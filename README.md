# Data Visualization Tech Trends 2026

A static GitHub Pages site for the infographic **Data Visualization Tech Trends 2026: What AI Is Changing**.

**Live site:** https://ericalvarado.github.io/dataviz-ai-trends/

The homepage shows the race edition, including the horse-racing “Race for AI in BI” section. The earlier edition, without that section, is linked from the page.

Pages serves these files from the root of the `main` branch. There is no build step. `.nojekyll` keeps Jekyll from processing the site.

In the repository settings, publish GitHub Pages from the `main` branch and the `/` (root) folder.
