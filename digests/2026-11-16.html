Data viz + AI weekly digest: Nov 9–16, 2026

The week's biggest shift: the chat assistant became a BI front end. Anthropic made Claude Data generally available, with certified metrics and live dashboards. In the same week, Tableau, Databricks, Sigma, and Snowflake each made their platforms easier for any agent to build on, read from, or migrate away from.

  1. Claude Data: certified metrics and live dashboards inside a chat assistant. On Nov 10, Anthropic moved Claude Dashboards out of beta as Claude Data, available on all paid plans. Data teams can certify queries, and charts built on them carry a "certified" badge. Users can draft data stories, and live sharing lets viewers see current numbers without holding the underlying connectors (certified queries and live sharing are still in beta). The launch partners are Amplitude, Mixpanel, Omni, PostHog, Sigma, and ThoughtSpot (Claude). On Enterprise plans, Claude Data turns on by default on Nov 20. Why it matters: this is the clearest case yet of the answers inside chat assistants theme. A general-purpose assistant now ships its own version of the semantic layer + trust stack (certified definitions, provenance badges, versioned dashboards). BI vendors face a choice: be the governed source behind it (Sigma, ThoughtSpot, and Omni signed up as partners) or compete with it.
  2. Tableau's November release: Tableau Studio and Data Apps go GA, but only on premium tiers. Tableau calls Studio "the new Tableau Desktop, built for the agentic era." It is an agentic workspace where an all-new Tableau Agent, guided by reusable Tableau Skills, authors metrics, calculations, dashboards, and extensions. Tableau says both Studio and Data Apps will be generally available on Tableau Cloud and Server in November 2026, and Q&A Calibration batch regression testing becomes GA in Tableau Next (Tableau). Tableau GM Mark Recher wrote on Nov 11 that the Data Apps open beta is live "with GA coming next week" (LinkedIn). Salesforce Korea said on Nov 16 that the cloud version arrives Nov 17 and the server version Nov 19, with more than 50 skills planned through Tableau Exchange (Chosun Biz). Why it matters: the race leader is rebuilding its flagship authoring tool around agentic analytics, and regression-testing agent answers against golden datasets is a concrete trust feature. The catch is the same as last week: the full Studio experience requires a Creator license on Tableau+, Cloud+, or Server+. Horse race: Tableau holds #1.
  3. Databricks' "Week of Genie": Genie Ontology goes GA and starts reading other vendors' BI semantics. On Nov 11, Databricks announced a second-generation, "always-on" Genie that takes a goal, delegates to subagents, and contacts people through an inbox and email (coming soon to preview/beta). It also made Genie Ontology generally available (Databricks press release). The blog details "external knowledge sources" (beta), which generate context from BI semantic models: Power BI is supported today, and Tableau and Sigma are "coming soon." Genie MCP makes the same context available to ChatGPT, Claude, and Microsoft Copilot. In a benchmark Databricks built with Turing, Genie with the Ontology passed 91% of task runs, which Databricks says is 1.6× the rate of the strongest frontier agent (Databricks blog). Treat that as a vendor benchmark. Also note that the blog calls Genie Search "Generally Available," while the press release lists it as "coming soon to preview." Why it matters: this is a full semantic layer play. Databricks wants to absorb business logic from rivals' BI models and serve it to every assistant. Horse race: Databricks ▲ again, now clearly pressing Qlik for #3.
  4. Snowflake ships a Tableau-to-Streamlit converter and strengthens semantic views. A Cortex Code skill in preview (Nov 12) converts a Tableau workbook into a multipage Streamlit in Snowflake app. Worksheets become Streamlit charts, calculations become Snowflake SQL, and filters and actions become widgets. The app is reviewed on synthetic data before it is switched to real tables (Snowflake docs). Separately, semantic view materializations went GA on Nov 11 (Snowflake docs), many-to-many relationships in semantic views entered preview on Nov 13 (Snowflake docs), and Snowflake CoWork can now answer location questions with interactive maps in chat (preview, Nov 10) (Snowflake docs). Why it matters: this is the second "leave Tableau with an agent" tool in two weeks, after ThoughtSpot's workbook import. The semantic layer work makes Snowflake's own definitions faster and more expressive. Horse race: Snowflake ▲ slight. It is aiming squarely at the leader's installed base.
  5. Sigma makes every workbook code and adds per-user AI spend caps. Workbooks and Reports as Code reached GA on Nov 10. Every asset now has a JSON/YAML spec that agents can read, write, version, and validate through the REST API. Sigma says more than 1,000 beta customers created over 50,000 workbooks from code. Its migration skills point coding agents at Cognos, Tableau, or Power BI dashboards and compare the results value by value (Sigma). On Nov 11, AI Budgets entered public beta, letting admins set a monthly AI spend cap for each user (Sigma). Why it matters: "BI as code" makes the dashboard a target for any coding agent (agentic analytics), and Sigma is also one of Claude Data's launch partners. Horse race: Sigma ▲. The dark horse keeps adding agent surface area and now has a migration story aimed at Tableau and Power BI.
  6. Hex says it cut the cost of an agent conversation by about 75%. A Nov 9 Hex engineering post says the cost per thread with the Hex agent fell from a high of $6.44 in January to $1.64. The savings came from cheaper models picked using its DataBench benchmark plus harness optimizations, and Hex says it makes "neutral or negative margins on AI consumption." It expects the code-first Hex 4.0 harness to take another 20–40% off (Hex). Why it matters: together with Sigma's AI Budgets and ThoughtSpot's usage meters last week, this shows AI cost becoming a visible product feature. Pricing for "chat with your data" is now a competitive axis alongside accuracy. Horse race: Hex = (steady, publishing real unit economics).
  7. Power BI will retire R and Python visuals; HTML and Vega visuals are on the roadmap. Microsoft announced on Nov 9 that built-in R and Python visuals (and R-powered custom visuals) will stop working in published Power BI reports in May 2027, including existing reports. It says no in-report migration will recreate them, and that its roadmap "includes planned HTML and Vega core visuals" (Microsoft Fabric Community). Why it matters: the largest BI platform is moving away from arbitrary script rendering and toward declarative, web-native specs. A first-class Vega visual would be a notable win for open grammar-of-graphics standards, which agents also find easier to generate and check. Horse race: Microsoft = for now. This is housekeeping, not an agentic launch, ahead of Ignite.
  8. Deals: money for "context" and for agent-scale analytics engines. Delphina raised $7.5M (total $15M), co-led by Radical Ventures and Costanoa, for its Context Factory, where agents build and maintain the business context behind AI analytics. It says business teams now ask 73% of the questions on its platform (Nov 12) (PR Newswire). Edelbyte, founded by former Azure Data Explorer leaders, launched with $70M led by Sequoia and Quiet Capital for an analytics platform optimized for AI agents (Nov 11) (SiliconANGLE). Why it matters: investors keep funding the semantic/context layer and the infrastructure behind agent-generated queries rather than new dashboard tools.
  9. Research and open source: designing dashboards for agents. "Agentic Dashboards" (arXiv, Nov 12; Lee, Kuo, and Ma) proposes a persistent visual analytics workspace where an agent chooses methods, views, and how they coordinate within a designer-defined "decision space." It also proposes criteria for evaluating the agent's behavior and failures (arXiv). In the browser stack, DuckDB profiled SQLRooms, a toolkit for local analytics apps that combine data, visualization, and AI-assisted analysis on the user's machine (Nov 12) (DuckDB). Plotly.js v4.3.0 (Nov 10) is a minor release that adds domainpad for fixed subplot gaps (GitHub). Why it matters: the paper recasts the visualization designer's job from building a fixed interface to setting limits on what an agent may decide. That is a useful frame for the trust theme as vendors ship agents that build dashboards themselves.

Horse race this week (editorial read): Databricks ▲ (Genie Ontology GA, reads Power BI semantics, Genie MCP everywhere) · Sigma ▲ (BI-as-code GA, migration skills, AI Budgets) · Snowflake ▲ slight (Tableau-to-Streamlit converter, semantic view upgrades) · Tableau = #1 (Studio/Data Apps GA, still premium-gated, and now a migration target for three rivals) · ThoughtSpot = #2 (no new launch verified in the window; Claude Data partner) · Qlik = / cooling (only a Talend Studio AI Assistant preview, Nov 10; no BI/agentic analytics launch) · Microsoft Power BI/Fabric = (R/Python retirement; Ignite is next) · Google Looker = (no major launch verified in the window) · Hex = (cost transparency). New entrant to watch: Anthropic's Claude Data, which now competes for the "answer" layer.

Worth watching: Microsoft Ignite (Nov 17–20) is Microsoft's chance to answer Claude Data and Databricks' Power BI reader. Watch for Fabric IQ / Power BI agent news and a date for the planned Vega core visual.
