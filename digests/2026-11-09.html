Data viz + AI weekly digest: Nov 2–9, 2026

The week's biggest shift: the governed context layer became the battleground. Snowflake, Google, Tableau, and Databricks all shipped "what does this metric mean" layers for agents in the same week, and Sigma and Tableau opened their agents to any MCP assistant.

  1. Snowflake puts a Business Ontology under every agent. At Snowflake Expedition 2026 (Nov 3), Snowflake announced Business Ontology (public preview soon), which stores approved business definitions and serves only those to agents, plus a generally available Cortex AI Gateway for agent policy, observability, and hard cost caps (Snowflake). Why it matters: this covers the semantic layer and trust themes in one release ("A Business Ontology governs the official meaning, a Semantic View calculates it"), and it builds on Apache Ossie semantic views.
  2. Google grounds Gemini in LookML and other vendors' semantic models. Google's Agentic Data Cloud update (Nov 4) made Knowledge Catalog grounding in semantic models from BigQuery, Looker (LookML), Databricks, Snowflake, dbt, and SAP generally available. It also turned Knowledge Catalog on by default in Gemini (preview), and Google cited an internal benchmark of "nearly 4x more accurate" agents (Google Cloud). Why it matters: LookML is now context that Gemini, Google's chat front door, can use directly. Separately, Looker 26.24 (Nov 6) made filters-as-tiles generally available (Looker release notes).
  3. Tableau opens up to "vibe-coded" Data Apps built by any agent. Tableau Data Apps entered open beta (Nov 3). These are custom web apps built in Tableau Studio "or with any third-party agent via MCP" that inherit Tableau security and semantics (Salesforce). A Nov 2 guide also details Tableau Next's Proactive Intelligence: autonomous insights, data alerts, and intelligence briefs pushed to Slack, Salesforce, or any MCP surface (Salesforce). Why it matters: Tableau is moving from dashboards to an agent backend, an MCP everywhere play. One caveat: an independent review notes that the MCP-ready Tableau Knowledge graph is only in the premium Cloud+ and Tableau+ tiers, and several external connectors are "coming soon" (nl2sql.ai).
  4. Databricks Genie reads PDFs, asks permission in Slack, and imports Power BI measures. Release notes from Nov 2–5 add four things. Genie Agents can analyze PDFs, decks, and images in Unity Catalog volumes with page-level citations (public preview). Agents answer using only the sources each user can access. Genie One traces export to a trace table (beta). Genie One visuals can be expanded in a side panel (Databricks AI/BI notes). Genie can also ask for tool-action approval inside Slack and Teams (public preview), and a beta lets it use Power BI semantic-model measure definitions (Databricks platform notes). Why it matters: reading a rival's semantic layer is a direct semantic layer move. An independent review flags that deleting a Genie chat does not delete its traces (nl2sql.ai).
  5. Sigma agents go "headless" into Claude, ChatGPT, and your own apps. Sigma showed workbook agents running outside Sigma through its MCP server and a REST agents API, with every call running as the calling user (Nov 4) (Sigma). Its Nov 6 release adds MCP-visible filter and control overrides, agents that set control values when run by API or MCP, API-key MCP auth (beta), and a MotherDuck connector (beta) (Sigma Community). Why it matters: this is the answers inside chat assistants theme at its clearest. The dark horse now has the most complete "build once, answer anywhere" story this week.
  6. ThoughtSpot's 26.11 release puts Spotter on Liveboards and adds usage meters. The release makes four Spotter features generally available. Spotter on Liveboards is grounded in each chart's filters. Users can search past chats and schedule updates. SpotterViz file upload builds a Liveboard from a Tableau workbook or a PDF. The release also adds admin-set Spotter usage limits and a 50 RPS per-Org API limit (ThoughtSpot docs, ThoughtSpot developers). An embedded "Auto mode" lets Spotter 3 pick the data model for each question (Nov 5) (BI Info). Why it matters: the Tableau-workbook import goes straight after the race leader. The usage meters cut against the unmetered/free AI pricing trend.
  7. Grok Bot's Data Bot: a chart-making "data scientist" taught by the data team. A Nov 2 post describes Data Bot, a Team Bot in Grok Bot. It uses shared skills for metric definitions, experiments, and chart best practices ("line charts for trends over time"), can turn a chart in chat into a Databricks or Hex dashboard, and, by the team's estimate, handled about 70 hours of work in a single week (x.ai). Why it matters: this is the chat front door in practice. The semantics live in curated skills and approved memory rather than inside a BI tool, and BI tools (Databricks, Hex) become where results land.
  8. Research: training small models to resist misleading charts. VizDAGuide (arXiv, Nov 2) trains compact vision-language models on reasoning structured as a dependency graph. On the misleading-chart benchmarks it used, fine-tuned Qwen3-VL-8B reached 71.88% relaxed accuracy on open-ended QA, above every general-purpose model the authors re-tested (they frame that comparison as context, not a strict ranking). On multiple-choice, GPT-5.5 still led with 80.00% (arXiv). Why it matters: this is the trust theme. Being fooled by misleading charts is still a measurable weakness, and the paper's error analysis puts most failures at reading values from the chart (grounding) rather than at detecting the misleading design.
  9. Open source: D3 ships its first release since 2024; DuckDB plus WebGPU charting appears. D3 v7.9.1 and v7.9.2 (Nov 3) are maintenance releases: they update dependencies, publish an ES-module bundle with npm trusted publishing, and revert a d3-delaunay collinear fix (GitHub). Separately, fjader 0.2.0 (Nov 2) is "an experimental, declarative charting library for Svelte and Python that queries DuckDB and renders with WebGPU" (PyPI). Why it matters: these are small but real signals for the browser handles big data theme. Neither is a major feature release.
  10. Deals: three small analytics deals and a big infrastructure round. Chord bought AI-BI startup Zenlytic in an all-stock deal of about $5M (Nov 3) (Axios). Querio raised $5M for "git-native" analytics that keeps metrics, permissions, and agent context in a customer-owned repo next to dbt models. It also released Unshackle, a free migration tool for leaving Tableau, Looker, and Power BI (Nov 3) (Pulse 2.0). Replit acquired Atta, an AI analytics startup whose chat-to-chart features are already live in Replit Agent (Nov 7) (BizStack). Ocient raised a $100M Series C for analytics that serves AI agents (Solutions Review). Why it matters: the money is going to portable semantics and to "chat that charts" outside classic BI.

Horse race this week (editorial read): Snowflake ▲ (Business Ontology plus AI Gateway GA) · Sigma ▲ (headless agents via MCP/REST) · Databricks ▲ (pressing Qlik for #3: Genie reads Power BI measures, files, and approvals) · Google Looker ▲ slight (LookML grounding in Gemini GA) · Tableau = #1 (Data Apps beta, but key pieces are premium-gated) · ThoughtSpot = #2 (strong 26.11, but adds usage meters) · Qlik = / cooling (no new agentic launch in the window; Semantic Models news was Oct 28) · Microsoft Power BI/Fabric = (no first-party BI launch verified in the window) · Hex = (quiet after Oct 27's Hex 4.0 and $100M; appears as a dashboard target in Grok Bot's Data Bot).

Worth watching: whether the competing "official definition" layers (Snowflake Business Ontology, Google Knowledge Catalog, Tableau Knowledge, Databricks Genie Ontology) actually exchange definitions through Apache Ossie, or whether each one becomes a new lock-in point.
